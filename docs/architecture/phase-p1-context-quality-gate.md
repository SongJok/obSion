# P1 任务上下文与质量基线架构门

状态：IN_PROGRESS
日期：2026-09-13

2026-09-14 增量见 [ADR0132](../adr/0132-recoverable-product-acceptance.md)：验收恢复
只续查已知 Run，不建立第二套执行器，不重复提交创建结果不明的任务。当前 API 重新
核验任务关系、权限和来源后读取答案并评分；旧分数不能替代复验，等待预算不重置。
报告 v2 记录提交阶段与截止时间，旧 v1 不补造字段，无数据库或事件迁移。
每轮实时外部查询、独立评分和生产发布资格均未因此完成，本门继续 IN_PROGRESS。

本增量复用唯一 Python 控制面、既有 Harness、Gateway/Policy、RunIntent 和审计模型。
路由只选择能力，不授予权限；同主体会话主题在当前来源权限核验后才可复用。
作者、调查和复核使用同一个任务问题；跨主体内容保持既有不可信历史处理。
结构化仓库选择在追问时重新经过当前可见目录过滤，旧选择被撤权时禁止自动退回其他
仓库；当前用户明确选择可覆盖历史。正常三轮任务与撤权分支有专门回归。

工作台目录浏览固定提交，逐项通过 Gateway/Policy 读取；前端额外检查响应来源并隔离
过期请求。该入口无源码运行、写入或外部链接跳转能力。真实厂商目录读取仍需实例配置
获得明确 Policy 许可，本地测试不代表已经激活。

证据预算算法为本地确定性摘取，保持原子正文块及来源，超限明确遗漏。未执行最终答案
不能成为质量通过证据。完整验收入口使用严格退出码；旧离线 status 仅表示所注明子集。
无新数据库 schema、事件版本或外部写能力，无需迁移。

新增只读运行版本接口和冻结任务验收 CLI，继续调用现有任务和受权限保护的来源接口。
独立评分合同不读取候选内部 VERIFIED，缺省评分为 NOT_RUN；报告区分知识子集与完整阶段。
部署字段只是声明，签名与 Worker 实际版本缺证据时阶段门持续阻断。

开发回归通过情况与剩余阶段门禁详见 [P1 报告](../phases/PHASE-P1-REPORT.md) 与
[ADR0131](../adr/0131-p1-context-and-honest-quality-baseline.md)。没有真实候选冻结、独立
保留集、三仓库档案和全部规定反向用例之前，本架构门保持 IN_PROGRESS。

本次增加用户资料/输出/约束槽位，仍复用 RunIntent 与原任务 API，无新数据库结构。
资料范围按当前 Policy/ACL 解析后由 Gateway 固定版本读取；调查动作的服务端白名单排除全库
搜索，且候选正文/续读目标限制为选定版本。来源检查扩大至带有本地 INTERNAL 能力版本来源
的原生索引 Evidence；受管来源检查继续保留，旧 Evidence 不重写。最新任务不可用或在快照后
撤权会停止追问；不能自动回退旧会话主题。真实跨入口、模型形式遵循和完整失效矩阵仍为未完成。
