# 正文投影与精确引用架构门禁

日期：2026-09-11。状态：VERIFIED_REPOSITORY_LOCAL。

- 作者、复核与出处定位使用同一正文顺序，保留原 Evidence 与位置摘要。
- 标题是未受信的来源标签，不能作为业务断言的正文证据。
- 只有实际被逐字引用支持的正文能成为新复核答案的出处，不按整个检索结果扩散引用。
- 隐藏模型无需的传输/检索元数据；完整审计与追溯信息仍按原 ACL 保留。
- 复核失败不增加发布权限，空选源不回退至全部检索命中。
- 无迁移、凭据入口或事件变更；保留旧路线和历史数据，实际质量与时延独立验收。

参见 [ADR 0112](../adr/0112-precise-knowledge-source-projection.md) 与
[验证记录](../phases/productization-precise-source-validation.md)。
