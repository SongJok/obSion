# 企业知识独立复核架构门禁

日期：2026-09-11。状态：IMPLEMENTED_VALIDATION_IN_PROGRESS。

- 复核在既有 VERIFY 与 ModelGateway 内执行，不增加凭据或外部工具路径。
- 逐 Claim 及完整答案均需支持，逐字原文校验不能由模型自报替代。
- 无授权正文、复核缺项、不可用、预算不足或非支持结论均不能发布生成答案。
- 复核结果、源位置摘要、成本及版本可追溯；模型判断不标为确定性重放。
- 兼容旧事件、历史评估及确定性摘录，GENERAL 保留日常问答合同。
- 真实语义用例、完整回归、数据库与界面分别验收；少量样例不代表目标准确率。

依据 [ADR 0110](../adr/0110-independent-knowledge-review.md) 与专项验证记录。
