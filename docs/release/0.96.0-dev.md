# Obsion 0.96.0-dev Alpha.1 post-conclusion context actions

The Harness investigation model ends in Critic-verified claims; the
collaboration model begins with tasks and decisions — but the two met
only by manual re-entry, losing source-Run provenance on the way.
Phase 96 closes the loop inside the Runtime inspector: each claim on a
completed run can become a workspace task or a decision record with
its evidence citations and provenance intact.

## What changed

- **Per-claim actions**: 转为任务 and 记录决策 buttons on every claim
  of a COMPLETED run pinned to a workspace.
- **Prefilled editable payloads**: ordinal titles, statement,
  provenance line, verification status, and evidence-cited rationale,
  composed by pure pinned builders.
- **Provenance preserved**: created records carry `source_run_id`, so
  Phase 92's provenance chips and inspector links render immediately.
- **Workspace pinning**: the target workspace comes from the run's
  pinned context; cross-workspace attempts keep failing closed with an
  actionable message.
- **Navigation**: "在协作中查看" closes the inspector and opens the
  collaboration view.

## Compatibility and migration

None. The collaboration API contract is unchanged; the phase composes
existing endpoints. Rollback is reverting the phase commits.

## Known limitations

- Actions appear only for COMPLETED runs pinned to a workspace
  context; ad-hoc runs outside a workspace stay read-only.
- All six Alpha.1 candidate gates remain PENDING operator-owned items.
