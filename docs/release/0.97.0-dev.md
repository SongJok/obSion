# Obsion 0.97.0-dev Alpha.1 Workbench interaction tests

The Web suite covered helpers, hooks, and parsers — but nothing drove
a mounted component the way an operator does. Phase 97 closes the
Phase 88 audit's last open reliability item with interaction suites
over nineteen operator-critical Workbench surfaces, and fixes
the defect the suite discovered: collaboration error guidance was
erased by its own follow-up refresh before anyone could read it.

## What changed

- **Composer interactions**: Enter submits, Shift+Enter and blank
  input do not, running turns the send button into stop, the context
  picker filters and adds, attachment chips remove.
- **Claim-action interactions**: verified claim → task with
  run-pinned workspace and `source_run_id`, success navigation into
  collaboration, actions hidden until COMPLETED, actionable
  source-Run-mismatch mapping.
- **Collaboration interactions**: task creation through the modal
  with an optional bounded source Run; assignee-invalid and
  version-conflict actionable messages pinned.
- **Automation interactions**: mounted workflow overview/detail,
  immutable version derivation and publication, validated manual
  triggers, schedule creation, and guarded retirement. The mocked
  publish response is checked against the production
  `{ workflow, version }` contract.
- **Runtime inspector accessibility**: all six tabs expose selected
  state and tab/panel relationships, use a single roving tab stop,
  and support ArrowLeft/ArrowRight/Home/End navigation. Interactions
  traverse context, Evidence, Memory, Claims, and Artifact details.
- **Governance-console interactions**: partial-domain degradation,
  stable-sender IM binding/revocation, Connector SDK discovery without
  Capability auto-binding, and health/scan/promotion refresh behavior
  are exercised against the production-typed Admin API boundary.
- **Governed-action interactions**: development/staging-only draft
  creation, idempotency keys, operator-authored preflight, independent
  approval decisions, bounded rollback reasons, and governed
  cancellation are exercised without exposing a production option.
- **Action modal accessibility**: draft, approval, and reason dialogs
  now expose modal semantics and stable accessible names.
- **Studio interactions**: accessible kind tabs, validation-only
  Workflow, immutable publish/promote/rollback, no-traffic-split compare,
  and selection-scoped comparison state.
- **Eval interactions**: one initial case fetch, dataset-scoped state,
  object-shaped case/run-binding JSON, fully pinned Evaluation Runs, and
  distinct same-dataset comparison.
- **Knowledge interactions**: normalized authorized search, recorded
  provenance, stale-Evidence invalidation, ACL-bearing upload, dedicated
  vendor ingestion routes, and bounded Feishu space synchronization.
- **Data interactions**: verified metric filtering, governed definitions,
  accessible detail tabs, explicit read-only lineage, error behavior,
  and generation guards against stale cross-metric responses.
- **Code interactions**: normalized authorized symbol search, distinct
  empty/error states, stale-result invalidation, and generation guards
  against cross-query responses.
- **Workspace asset interactions**: immutable file history, safe paths,
  classified upload/download, Artifact filtering/preview/upload, and
  refresh preserving detail by Artifact ID.
- **Workspace projection interactions**: persisted Reports, unique valid
  Dashboard panel references and error recovery, non-executing validated
  SQL, immutable Evidence envelopes, and Event Store Timeline payloads.
- **Offline wheel contract**: Hatchling is locked as a dev dependency;
  the frozen Event/Error resource test builds a real wheel offline without
  build isolation, and the SBOM is regenerated from the updated lock.
- **Migration round-trip CI**: Phase 5 auth-session and Phase 79 operator
  invocation migrations now run upgrade/downgrade/re-upgrade in separate
  PostgreSQL matrix jobs. Both run Alembic drift detection and gate the
  container candidate job.
- **Defect fix**: the mutation handler now refreshes first and
  surfaces guidance after — version-conflict recovery instructions
  survive the reload they trigger.

## Compatibility and migration

No backend route, schema, permission, or API shape change. Hatchling and
its lock closure are development/build-only dependencies; runtime packages
are unchanged. The workflow change executes existing destructive migration
tests only in disposable databases. Rollback is reverting the phase commits.
