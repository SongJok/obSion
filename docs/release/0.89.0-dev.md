# Obsion 0.89.0-dev Alpha.1 typed Evidence views

goal.txt section 57 defines the Evidence Panel as one of the product's
deepest differentiators: clicking a conclusion must surface typed Metric,
Log, Deployment, Git Diff, and Config Diff evidence — not a generic JSON
dump. The control plane has persisted those rows since the early phases
(one envelope metadata record plus a normalized JSON content payload per
Evidence), but until this phase both the Runtime inspector and the
workspace Evidence page rendered every row as raw `JSON.stringify` output.
Phase 89 closes that gap entirely on the rendering side: no API, schema,
capability, or runtime change, and no invented fields.

## What changed

- **Envelope-driven classifier** (`apps/web/src/lib/typed-evidence.ts`):
  dispatch keys mirror exactly what the control plane normalizes —
  `events[]` (observability operations), `items[]` (engineering
  operations), `columns`/`rows` (data queries), `plan`/`validation`
  (`sql.explain`), `hits` (knowledge retrieval), and `text` (document
  attachments). `CODE` items get a dedicated symbol projection. Every
  accessor is a type guard; anything unrecognized falls through to the
  generic view.
- **Typed renderers** (`apps/web/src/components/evidence-content.tsx`):
  observability events with severity chips and attribute projections;
  engineering change items with `git.diff`/`config.diff` specialization
  (patch view and before/after pairs); Code Graph symbol cards with
  `path:start-end` locations; real HTML tables for query results; explain
  plan plus validation ledgers; the existing knowledge citation
  provenance; and readable document text. Display bounds (100 rows, 200
  entries, 12 attribute chips) sit on top of the server-side budgets.
- **Full metadata ledger** (`EvidenceMeta`): `observed_at`, `ingested_at`,
  confidence, classification, permissions, content fingerprint,
  `step_id`, `run_id`, and lineage render only persisted fields, so the
  Claim → Evidence navigation that already existed now lands on an
  auditable, fully-attributed record.
- **Integration**: the Runtime inspector detail and the workspace
  Evidence page share the same components; the `Evidence` TypeScript type
  now matches the REST projection exactly (`run_id` required, `step_id`
  and `ingested_at` present), and the dead "no Run" branch is gone.

## Compatibility and migration

None. No endpoint, schema, event, or configuration changes; rollback is
reverting the phase commits.
