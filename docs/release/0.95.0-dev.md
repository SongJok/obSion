# Obsion 0.95.0-dev Alpha.1 schema-driven chart renderer

The Harness has emitted a Vega-Lite v5 subset for CHART artifacts since
the data-analysis phases — bar, line+point, and text marks with x/y/
text encodings — but the Workbench rendered every mark as horizontal
bars. Temporal series lost their chronological shape and single-number
results rendered as a degenerate bar. Phase 95 makes the renderer
schema-driven: it parses the emitted spec and renders each mark
faithfully, dependency-free.

## What changed

- **Line mark**: temporal series render as an SVG line chart with grid
  ticks, dot tooltips, and axis labels, sorted chronologically.
- **Text mark**: single-number results render as big-number KPI cards.
- **Bar mark**: nominal series keep the horizontal-bar look, now
  schema-driven and capped (20 bars, 200 line points).
- **Fail-closed parsing**: unknown marks fall back to bar; content
  without numeric values shows the explicit empty notice.
- **Producer pinned**: control-plane tests lock `_chart_contract` mark
  selection and numeric normalization against renderer drift.

## Compatibility and migration

None. CHART artifact content is unchanged; only rendering improves, on
every surface that shows artifacts (Artifacts, Dashboards, run
previews). Rollback is reverting the phase commits.

## Known limitations

- The renderer implements exactly the bar/line/text subset the Harness
  emits; richer marks (area, scatter, color series) would require
  producer changes first.
- All six Alpha.1 candidate gates remain PENDING operator-owned items.
