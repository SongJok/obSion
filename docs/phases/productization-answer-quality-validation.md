# 中文提问与回答发布验证

日期：2026-09-11。状态：本地实现与真实测试租户样例验证通过；完整 M1 与生产门禁未完成。

本轮从与 GitHub `origin/main` 完全一致的干净工作树开始，在 `codex/answer-verification` 分支
实施 [ADR 0106](../adr/0106-answer-publication-and-chinese-retrieval.md)。无自动 Git 提交、推送或生产晋级。

## 实现

- 中文自然提问使用有界二字召回；PostgreSQL 在当前租户、版本和 ACL 查询中完成匹配。
- 模型 Claim 整体校验，拒绝外来引用、空陈述及非法置信度，错误 JSON 拒绝发布并保留计费。
- 答案正文核验在追加引用之前执行；WITHHOLD 发布明确说明，保留 PARTIAL Claim 和独立核验记录。
- 核验规则版本升级为 v3，既有 Event/REST/SDK 结构保持兼容。

## 失败复现

初始 21 项专项中 20 项失败：包括中英文无关答案被标 VERIFIED、非法引用静默过滤、非有限
置信度被接受。中文端到端用例同时发现已有资料无法召回。修复后的首批组合 34 passed / 2 skipped。
后续模型格式与计费专项加入后，答案专项 27 passed。

PostgreSQL 首轮一项断言失败源于测试误用了 REST 不支持的 `sources` 参数，混入其他测试的合法
可见文档。已修正测试的资料定位，保留原有拒绝和跨租户断言；没有通过放松权限或修改运行时来规避。

## 迁移与真实 PostgreSQL

本轮无 schema 变化。创建独立 PostgreSQL 17 验证实例，空库升级至 `d0e2f5a7b3c4` 与 Alembic
漂移检查通过。修正后的跨数据库中文检索组合 9 passed（包含 PostgreSQL、SQLite 和词项契约）。
未降级业务库，未修改既有生产资源。

## 真实模型发现与修复

最初本地管理员的真实模型测试暴露出仅靠检索片段无法保证问答可用：README 定义问题被通用摘录替代，
不存在的“火星量子通信模块”问题也返回同样摘录且标为已核验。修复空 Claim 被回退覆盖后，继续发现
模型返回 `claim` 字段，而服务端要求 `statement`。在首条平台提示中明确输出形状，并在兼容模型投影中
合并连续的首部系统提示后，真实正例开始直接回答问题。没有接受未经定义的字段别名或放松引用检查。

最终内部契约为 Output contract v2，增加明确的 answerable 布尔信号。即使模型把“资料未记载”写为
带引用的 Claim，answerable=false 仍保留为未知；旧版 answer/claims 生产者继续兼容。诊断日志仅含
本地选定的计数、字段类别和布尔值，不含候选正文、证据正文或凭据。
