# Web 布局与易用性优化验证

日期：2026-09-05

## 范围

在工作区已有登录、导航分组和移动端修复的基础上，优化工作台壳层、首页与输入操作，不改变控制面 API、认证、权限、运行编排或数据归属检查。本次不是新增阶段，不涉及数据库迁移。

## 改动

- 最近任务前置到功能导航之前，列表限高滚动，避免长历史挤占全部入口。
- 增加功能搜索，支持中文名称、分组名称及英文标识；选择后清空，支持清除按钮和 Escape。
- 保留全部 17 个功能入口及原有分组、当前页标识、折叠模式可访问名称。
- 突出新建任务主按钮，改善搜索框、用户身份区域和折叠侧栏底部布局。
- 首页使用更直接的引导文案，示例卡片根据对话区域实际宽度而非整个窗口宽度切换排列。
- 附件与上下文按钮增加文字标签，添加键盘操作提示及提交中反馈；小屏隐藏辅助提示，保留主要操作。
- 统一回车与按钮的发送限制，上传中、提交中、运行中或禁用时不重复提交，中文输入法确认不触发发送。
- 优化小屏内边距、标题截断和触摸尺寸；修复关闭运行详情后移动端出现重复打开入口的问题。
