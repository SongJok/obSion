# ADR 0112：正文投影与精确引用

日期：2026-09-11。状态：实施与验证中。范围：M1 问答可用性。

实际 README 回答仍把检索来源、外部编号等元数据写入正文；检查还发现一条 Evidence 会包含多份
文档，既有引用器把关联 Evidence 的所有 hits 都列成出处，包括未支持答案的文档。
模型输出提示不能独立保证正确引用，修复必须进入证据投影与发布链路。

新增共享的 DOCUMENT 正文枚举：保持原复核算法的 text、content、hits.content 顺序，忽略空白与
非正文项，保存稳定 body_index 与原记录的关系。正文不改写，不去重、不重排，既有位置摘要仍可重放。
KNOWLEDGE 作者上下文只保留顶层 Evidence ID、文档标题、正文与正文序号，隐藏资源、检索参数、
连接来源、chunk/外部编号、评分及版本元数据。标题用于辨认来源，仍属不可信标签，不能替代正文事实。
其他路线、工具结果与公共 evidence_context_segments 默认调用保留旧格式。

独立复核接受后，引用候选只能来自实际逐字引用定位到的正文记录。不能把“同一 Evidence 中出现”
当作“支持当前结论”。无片段编号的不同正文也分别保留；被拒绝或没有正文引用的评估不回退到全部 hits。
当前受支持原文引用增加可选 body_index，完整来源、版本、外部编号与 Evidence 继续留在受保护
Artifact/审计记录。面向用户的引用只展示编号、标题与可用版本；标题转义为文字，防止被当成链接或图片。

继续使用原 Gateway、Policy、原 Run/组织 Evidence、数据分级、预算和 WITHHOLD。无新连接器、
凭据入口、数据库迁移或新事件；不重写历史回答，不改变专业路线和旧确定性摘录的选源合同。
独立模型判断仍可能错误，本文不声明达到知识准确率、引用准确率或普通问答时延目标。
