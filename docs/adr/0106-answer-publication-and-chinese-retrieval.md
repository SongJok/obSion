# ADR 0106：回答发布门禁与中文自然提问检索

日期：2026-09-11。状态：接受。范围：Phase 98 / M1 的问答可用性修复，不推进生产晋级。

## 可复现问题

1. `Reflect` 返回 `WITHHOLD` 后，`Respond` 仍将原始候选回答写入答案 Artifact、报告和
   `answer.delta`。IM 从该 Artifact 读取正文，因此核验拒绝没有成为实际发布门禁。
2. 中文问题在 Critic 中直接跳过主题检查；英文检查允许 `the` 或仅存在于 Claim 中的词命中。
   引用标题又在核验前追加到正文。测试证明“香蕉会发光”的无关回答搭配真实资料 ID 可通过核验。
3. 模型 Claim 的非法条目/外来引用被静默删除，剩余合法条目可能让整段候选正文继续发布；
   非对象 JSON 会触发 AttributeError，NaN/Infinity/布尔置信度没有被拒绝。
4. 知识检索把连续中文当作整词。自然问句与资料句子不完全相同时，SQLite 子串和 PostgreSQL
   `simple` 全文索引都无法召回已有的报销制度内容。
5. 真实模型测试发现，资料未记载的“火星量子通信模块”问题仍返回 README 摘录并被标为已核验。
   模型返回空 Claim 时，合成层将其丢弃并生成“检索到若干片段”的 Claim，掩盖了问题未被回答。
   既有提示也未明确 Claim 字段以及顶层 Evidence ID 与文档分块 ID 的区别。

## 决定

- 将 `WITHHOLD` 执行为真正的正文发布屏障：发布固定的证据不足/核验未通过说明，清除候选引用。
  原 Claim、Evidence、核验和 Reflect 记录仍按现有权限保存以便审计；拒绝的 Claim 为 PARTIAL。
  Run 的 COMPLETED 仍表示本次执行结束，不能解释成结论正确或业务目标成功。
- 先检查候选正文，再追加引用。英文排除常见虚词，中文以二字片段检查主题锚点；不再让独立 Claim
  或追加的引用标题替正文通过检查。该检查是确定性的低限相关性保护，**不是语义蕴含或事实正确性证明**。
- 模型 Claim 集合整体校验：最多 20 条、非空陈述、同 Run 的实质证据、唯一合法 ID，以及数值型
  0—1 有限置信度。任何非法条目使整份模型候选失效，不部分删改后发布原文。
  非对象 JSON、空白回答、非法 Claim 和空 Claim 均保留为无可发布结论；不改用检索数量证明答案。
  已配置模型的知识/支持问答在模型不可用时同样保留为未知；模型返回的 token 与费用照常计入预算。
  无可用路由与已选端点失败由 ModelGateway 的内部 no_model_route 信号区分。前者允许既有本地
  授权证据摘录，后者不能回退为声称回答了问题的检索摘要；不因已有默认 Profile 就误判为已配置端点。
- 在既有不可变提示版本之外，将运行时 `Output contract v2` 附加至首条平台系统提示，明确 JSON 字段、
  顶层 Evidence ID、用户语言、直接回答、资料不足时空 Claim，以及设计目标不能冒充已验收能力。
  提供具体 JSON 形状示例。该内容通过既有 ContextBuilder 计入平台提示预算，不改写历史 PromptVersion。
  空 Claim 的模型原文也不能直接发布；最终仍由 Critic → Reflect → Respond 执行静态未知说明。
  `answerable: false` 表示未回答具体问题，即使附有“文档没有记载”的 Claim 也不能据此转为已核验答案。
  `answerable` 出现时只接受布尔 true 为可回答信号；旧版仅含 answer/claims 的生产者保持兼容。
- OpenAI-compatible 投影将连续的首部系统消息按原顺序合为一条；防止仅消费首条系统消息的连接
  丢掉后续 Agent/Skill 约束。用户资料、工具历史、非首部系统消息保持原角色和顺序，调用者消息不被修改。
  本地真实端点在独立系统段方式下连续返回 `claim` 字段；首条平台提示携带契约后开始返回受支持的
  `statement`。这是黑盒兼容性证据，不声称已审计外部服务内部实现；也不为通过测试而接受未经定义的字段别名。
- 统一使用最多 32 个去重词项；拉丁文本保留词粒度，连续中文使用二字片段。PostgreSQL 将中文
  子串条件与既有全文条件组合在同一条租户、ACL、来源、当前版本过滤查询内，再排序和限制候选。
  参数绑定与 LIKE 转义保持开启，不先把未授权语料拉到应用层。向量检索继续使用既有 Model Gateway。
- 新核验记录的规则集版本为 `phase20.critic.v3`、评估器版本为 `3.0.0`；不回写历史记录。
  不改 Event v1、REST/SDK 响应结构、不引入第二个模型或权限执行路径。
- 真实钉钉回执还暴露出 readTimestamp 秒/毫秒单位差异。接收适配层将秒规范化为毫秒，保持内部
  RobotQueryResult 契约与持久层不变；负数/非整数仍拒绝，超大值仍由有界日期转换保护。
  未读回执的零时间戳不写成 1970 年的已读日期；持久化为 null。既有历史派生日期不自动回写。

## 迁移与回退

无新增表、字段或索引，无需 schema 迁移。独立 PostgreSQL 完整前向升级及 Alembic 漂移检查用于
验证当前 ORM/迁移链仍一致。更新控制面后新 Run 生效，历史答案不重写，也不重新发送历史 IM 消息。
若需回退，先停止接收新问答并恢复上一镜像；不得删除审计或把旧 WITHHOLD 结果重新标为 VERIFIED。

## 验证及限制

专项覆盖中英文无关回答、引用标题/Claim 不能补救正文、Artifact/报告/Event 一致性、非法引用与
置信度、错误 JSON 拒绝及计费、模型弃答不被摘录覆盖；真实 PostgreSQL 与 SQLite 覆盖中文自然提问、版本更新、即时撤权
和跨组织隔离。运行结果见 [问答验证记录](../phases/productization-answer-quality-validation.md)。

中文二字召回会带来同词不同义候选，子串分支可能增加大语料扫描成本；本次不宣称中文正确率、
p95、语义事实验证或大规模性能已达标。仍需真实任务保留集、来源蕴含检查、跨语言与歧义评测。
未配置模型的既有确定性检索摘录模式保留兼容性，不能将其 VERIFIED 当成语义问答质量证明。
钉钉群受众、四意图完整 UAT、云效来源到 Harness/沙箱及 M2—M6 不由本增量替代。
