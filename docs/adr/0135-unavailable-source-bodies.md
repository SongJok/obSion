# ADR0135：扫描完成但正文不可用时停止生成

状态：Accepted
日期：2026-09-15

## 问题

ADR0133 的扫描回执证明外部采集已执行，不能单独证明采集到了完整正文。
日常开发环境升级后的真实提问发现：DWS 登录失效，目录扫描结束，但正文全部拒绝或
不完整；Run 仍标记 READY，随后调用7次模型，约175秒后才返回资料不足。
没有发布虚构答案或旧正文，但来源状态和恢复提示不准确，并产生无效模型调用。

## 决策

沿用原 PostgreSQL 扫描回执与 Gateway/Policy 同步流程。存在未完整取得的非目录文档时，
进一步检查本轮来源集合中是否至少有一条具有文档关联、当前读取时间、当前读取世代和
未过期访问资格的 READY 正文。没有时返回固定原因 `source_content_unavailable`。
已有调用方将其投影为 BLOCKED/SOURCE_UNAVAILABLE，跳过回答与调查模型，提示用户检查
钉钉连接、登录授权及同步服务，或明确选择上传资料。

部分正文成功时继续保留 `incomplete_documents`，查询仍受逐文权限、版本和发布屏障约束；
全空目录不被误报为读取故障。当前来源以外、旧读取时间、旧世代或过期记录不能抵消失败。
不读取私有正文判断登录，不增加默认授权，不从本地旧索引回退，不建立第二套执行器。

## 兼容、迁移与验证

增加一个来源不可用原因，复用已有响应状态；无新数据库列、事件或能力版本。
日常数据库采用已验证的 `c5d7e9f1a3b5`，旧版本描述符保留，新任务绑定120秒能力版本。
回退本增量应同时回退 API 与固定源码的宿主同步服务，不需要数据库降级。

专项覆盖全部拒绝/不完整/失败/待处理、旧读取、旧世代、过期、混合成功与空目录。
真实一次性 PostgreSQL 通过正常任务入口验证并发、无模型调用和既有迁移往返。
部署、真实故障复测及剩余验收状态见 [P1报告](../phases/PHASE-P1-REPORT.md)。
登录恢复后的真实知识问答、独立语义评分、云效/日志多源验收仍未因此完成。
