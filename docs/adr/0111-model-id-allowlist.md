# ADR 0111：部署级模型 ID 限制

日期：2026-09-11。状态：已采纳并完成本地切片验证。

用户限定本地模型为 kimi-k3-kimi 和 kimi-k2.7-kimi。检查发现环境中的模型名称已经更新，
数据库旧端点仍保存其他模型名称；环境变量不会自动改写数据库记录。

在现有 ModelGateway 的共同候选选择入口加入 OBSION_MODEL_ALLOWED_IDS，按准确、区分大小写的
模型 ID 筛选，覆盖聊天、知识复核、嵌入、敏感数据私有路由和备用端点。
在凭据解析与供应商请求之前过滤，不允许优先级、旧绑定或 fallback 绕过。
未配置或 null 保留既有部署兼容性；显式 [] 拒绝全部模型。操作员可用列表收窄，不能扩大
现有分级、供应商、域名、能力或 Policy 许可。空路由沿用现有模型不可用合同。

本地开发配置仅允许用户指定的两个模型；经现有管理员 API 添加端点与绑定，保留历史调用
和旧端点的审计记录，旧端点在此部署中不可调用。不自动扫描或尝试其他模型，不暴露凭据，
不把这个部署偏好写成全产品的固定模型名单。

无数据库迁移、破坏性 API 或新外部调用路径。回滚时必须保留限制，禁止回退到不支持限制的
旧网关后重新启动；必要时先停服务。实际供应商响应的模型别名不构成底层模型身份的独立证明。
