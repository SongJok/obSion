# ADR 0140：独立评分协议的有界诊断

状态：Accepted（P1 产品化增量）
日期：2026-09-15

## 问题

固定候选b23431b的真实保留集执行出现多次 `independent_judgment_invalid`。该结果正确
阻止了无效评分，但未区分JSON、字段类型、规则覆盖及答案/来源引文问题，不能据此定位
故障。不能为排查而把原始模型响应、企业正文或验证异常全文写到公共日志。

## 决策

保持原BLOCKED状态与reason不变，在评分证据和同一不可变审计中新增固定
`judgment_diagnostic`。只允许JSON无效、重复键、深度错误、schema无效、规则覆盖不足、
缺少支持、答案引文无效、来源引文无效、引文不充分和其他协议错误等预定义标签；成功及
与判断协议无关的失败返回null。绝不导出异常文字、输入字段名、原始模型输出或来源片段。

JSON对象出现重复键时拒绝解析，包括嵌套规则；后出现的true不能覆盖之前的false成为
有效判断。已有严格类型、每项规则覆盖、逐字引文、全部语义判断及提交权限锁保持不变。
诊断本身不引入重试，不改变冻结问题和金标，不自动将旧BLOCKED结果重算为通过。

## 兼容、迁移与限制

新增字段位于既有开放的evidence/metadata对象中，状态、reason和API顶层合同兼容；没有
新schema或事件版本。评分语义政策没有变化，政策摘要保持原值。
该增量只提升可诊断性，不宣称已修复真实模型格式错误或完成评分器校准。后续诊断调用
必须是另外一次有审计的运行，并保留原验收失败。
