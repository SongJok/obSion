# ADR 0110：企业知识答案的独立原文复核

日期：2026-09-11。状态：实施与验证中。范围：M1 回答质量。

正确引用 ID、主题词及数值存在检查不能核验否定、适用条件、因果或设计目标与验收状态。
在现有 Harness VERIFY 步骤中增加一次独立 ModelGateway 复核，检查逐 Claim 与完整候选答案。
仅 KNOWLEDGE 且通过先前确定性检查的生成答案进入复核；平台既有逐字证据摘录可按完全相等的
候选内容与 Claim 契约识别，不新增模型依赖。GENERAL 和其他专业路线保持各自合同。

复核使用独立固定平台策略与封闭 JSON，问题、候选答案、Claim、来源正文都作为不可信输入，
不传入 Agent 描述、历史、Memory 或工具，不接受候选作者自报置信度作为复核输入。
每个 Claim 必须获得 SUPPORTED / CONTRADICTED / INSUFFICIENT，完整答案还必须被确认有据并回应问题。
SUPPORTED 必须携带逐字原文，代码检查每条引用属于该 Claim 所链接、当前组织及 Run 的 DOCUMENT 正文。
不接受标题、URL、评分或其他 Run 数据。任何缺项、假引用、截断或非支持结果都拒绝发布。

沿用现有 ModelGateway 的凭据、路由、最高数据分级与剩余 token/费用预算；无新模型传输或权限。
复核调用关联 VERIFY Step，成本累计到同一个 Run。预算、模型不可用或非法结果进入 WITHHOLD，
不以未执行检查替代通过，也不回退到未经核验的生成答案。

将版本、输入与候选摘要、模型结果摘要、逐 Claim 判断及原文位置/长度/摘要保存到 VERIFY、Claim、
答案和 VerificationAssessment。原文继续从授权 Evidence 读取，不复制到事件或运行日志。
复核评估版本为 v4，replay_lineage.deterministic=false，保留旧确定性评估和事件 v1/v2 格式；
不重写历史评估。现有 JSON 元数据字段容纳新增记录，无数据库迁移或破坏性 API 变更。

模型复核仍会出错，与生成模型相同的路由可能有相关偏差。原文一致性是代码可核对的事实，
语义判断是模型复核结论，不能宣称为形式化证明或企业知识准确率已达到目标。
必须验证否定、条件、指标关联、设计目标、来源注入、缺项、完整答案覆盖、失败成本与发布屏障；
真实模型样例、全量回归、持久 PostgreSQL 和 UI 说明分别记录。

实际 README 验证发现作者把引用的标题/版本/授权元数据生成了事实 Claim，而正文复核不能证明它。
收紧作者输出规则：事实来自文档正文，引用信息交给既有平台渲染。保持正文复核标准，不让元数据
成为任意正文断言的证据。元数据可在受控引用区展示，不能据此声称功能已实现或经过验收。
