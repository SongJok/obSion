# ADR 0115：持久知识源与可撤销读取授权

日期：2026-09-11。状态：接受；数据库、受管入库与访问屏障已实现，后台循环未完成。

## 问题

正文读取成功并不意味着可以永久复制原权限。现有普通知识 ACL 允许本地管理员按分类读取，
且正文未变化时复用既有 DocumentVersion。若把外部用户标识写入普通 ACL，或者把权限新鲜度
放在不可变版本元数据中，就会产生越权或永不过期的历史授权。

## 决策

新增 PostgreSQL 事实表 `knowledge_sync_sources` 与 `knowledge_sync_items`。
来源固定已有 ConnectorConfigurationVersion、本地用户、安装域 sender 绑定、corpId 与 appKey；
不复制实际密钥。相同配置/绑定注册幂等，关闭来源后再次注册不会自动恢复。
复用现有配置版本与独立撤销账本，不新增另一套凭据版本。

受管入库只由控制面工作代码接受真实 Gateway 结果，不能建立允许客户端上传“读取证明”或
正文结果对象的公共接口。入库重新检查当前用户、L2 Policy、来源状态、安装和连接快照。
不完整正文持久标为 PARTIAL，不建立可供问答读取的文档；重新读取发现缺口时撤销旧访问租约。
完整正文以 RESTRICTED 和明确本地 USER ACL 入库，与访问记录同一事务提交。授权更新不修改
历史版本元数据；相同内容与来源身份不制造重复版本，来源 revision/结构摘要/解析版本变化
则生成新的历史版本，避免新引用继续指向旧来源版本。

保留 `dingtalk-managed` 来源名称作为强制授权边界。搜索、全文与下载除了普通 ACL，还检查：

- 对应 READY 逐文档记录存在，来源启用，最多五分钟的读取授权尚未过期；
- 当前本地用户与原绑定用户一致，用户、安装和 sender 绑定均有效且未撤销；
- 安装组织/应用、供应商 sender 与冻结配置一致；连接仍启用且配置、grants、egress 和凭据引用未变；
- 配置版本未被撤销。

无来源记录、任意本地管理员、其他组织或本地配置替换均不会绕过此约束。
直接本地关闭/撤销在下一次读取生效；远端撤权在下一次授权检查或租约过期时生效，
不宣称已经有远端变更事件或零延迟撤权。运行中答案发布与历史会话的来源再校验仍须后续接线。

数据库持久保存扫描代次、继续位置、租约 token 与到期时间。领取使用 PostgreSQL SKIP LOCKED
及条件 UPDATE；继续位置提交也必须命中当前 token/代次/有效期，过期工作不能覆盖新任务。
只有完整扫描、队列和游标耗尽后才将未出现节点标记 MISSING；部分扫描不推断删除。
目前实现的是调度原语，尚未启动自动发现、读取和重试循环，不能称为后台同步已交付。

## 迁移与验证

前向迁移 `e1f3a6b8c5d7`（父版本 `d0e2f5a7b3c4`）新增两表、同组织复合外键、状态/租约
约束和索引，为 documents 增加同组织唯一键；不回填可信源、不改变已有文档来源。
错误字段位于 canonical `obsion.db.models`，保留既有静态错误契约。

初次刷新测试暴露 READY 状态先写空租约的自动 flush 约束失败，已通过在同一事务中先进入
PENDING 再恢复租约修复，未削弱数据库约束。SQLite 与隔离 PostgreSQL 合计28项通过，
涵盖完整/不完整、幂等刷新、来源版本变更、各种撤销、管理员隔离、继续位置和过期 token。

真实 zziv 十篇经 Gateway/Policy/DWS 读取后，三篇在隔离 PostgreSQL 完成受管入库并可检索，
七篇 PARTIAL 未建可检索文档；关闭来源后三篇均不可访问。此次 blob 存储使用显式内存测试
适配器，不代表生产持久 blob 或后台重启验收。无模型调用、消息外发或运行中 API 部署。
记录见组织文档专项报告和 `20260911-dingtalk-governed-ingest.json`。
