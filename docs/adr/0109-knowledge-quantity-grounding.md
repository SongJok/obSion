# ADR 0109：企业知识回答的金额与比例来源检查

日期：2026-09-11。状态：已实施，本地增量验证通过。范围：M1 回答质量。

真实代码回归复现：文档规定报销上限 500 元，模型回答 1000000 元，仍能凭正确 Evidence ID、
主题重合与模型自报置信度获得 verified=true。已有 Claim 关联和问题覆盖检查无法发现这种错误。

在既有独立 Critic 内增加确定性检查，仅用于 KNOWLEDGE 路线。逐 Claim 对比其链接的 DOCUMENT
正文中的显式金额和百分比；再对最终候选正文检查，防止正确 Claim 掩盖错误答案。
数值保留正负号、币种和数量级，统一全角数字、千分位、小数、元/人民币/CNY/RMB、美元/USD、
欧元/EUR 与万/亿量级。金额不在关联正文中就追加 HIGH VALUE 冲突，由现有 Reflect WITHHOLD
与回答发布屏障拒绝发布。文档标题、URL、召回评分、未关联 Evidence 不作为数字支持。

无新外部调用、凭据、授权、执行器、模型提示或数据库字段。沿用已有冲突事件开放 reason_codes 字段；
不改变冻结事件 schema。旧 API 形状不变，不重写历史 Run；无迁移，回退 Critic 调用即可取消此增量。
GENERAL 日常问答不要求企业 Evidence；数据和事件分析保留各自既有核验合同。

这是有意收窄的负向检查，不是完整语义蕴含证明。阿拉伯数字标记的金额和百分比之外，中文数词、
日期、无单位数字、指标关联、否定、条件和单位换算推理尚未解决。同一正文存在该数值不代表它属于
回答所述指标。没有受控计算证据的派生金额可能被拒绝，不能仅凭模型自报计算成立。
后续语义核验仍需独立验收，不能将该规则宣称为阻止所有错误回答。

必须覆盖错误金额/比例/币种/正负号、正确等值表达、逐 Claim 关联隔离、正文与 Claim 不一致、
最终 Artifact/Report/answer.delta 发布屏障、原知识问答与日常问答回归。
