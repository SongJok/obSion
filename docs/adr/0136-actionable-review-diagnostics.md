# ADR0136：可定位且有界修正的独立复核

状态：Accepted
日期：2026-09-15

## 背景

ADR0135 的真实实时问答取得新受管证据后仍被 `grounding_review_invalid` 拦截。
该状态合并了 JSON、结构、声明覆盖、引用、输出截断等失败，已有账本只保存响应摘要，
无法事后判断具体原因。部署具体诊断后，新的真实提问确认失败为 `quote_not_exact`。
重复提问或盲目改写作者答案不能作为根因修复。

## 决策

保留唯一 Harness 的既有复核调用、Model Gateway 的权限/预算/审计与发布屏障。
在同一严格校验器中产生固定枚举诊断，通过原 GroundingAssessment 保存到验证步骤、
验收记录和回答产物。诊断只描述失败规则，不包含原始响应、正文、引用文本或提供商错误。
旧 `grounding_review_invalid` 原因和 `validate_review` 返回合同保持兼容；成功或有效否定
不增加诊断字段。旧记录没有具体诊断时不推测或回填。

区分 JSON 解析失败（含解析深度限制）、输出截断、顶层字段、整体判断类型、声明覆盖、
声明字段/编号/结论、引用列表/字段/来源/文本、引用原文匹配、实质长度和引用覆盖失败。
截断优先报告，不能将完整JSON的局部截断响应或模型自称支持当作通过。
仅当第一次复核的整体判断和每条声明均声称支持、而本地失败是 `quote_not_exact` 时，
允许一次引用修正。第二次仍使用同一候选、声明与证据，只追加服务端固定要求：从单一正文块
复制原文，不拼接、不规范化或转述；找不到支持时必须否定或说明不足。无原始复核响应回灌。
任何语义否定、问题未完成、其他结构错误或截断均不能触发此重试。

每次调用重新使用剩余输入、输出与费用预算；修正前后核查已知取消和截止状态，迟到修正
不得支持发布。每次请求使用原 Model Gateway 的权限、密级和审计，账本保留策略类型、
请求指纹、响应摘要（如有）和固定结果；失败调用也不伪造响应摘要。
最多两次复核，第二次仍失败就停止；之后原来源再检查、Critic、语义调查和发布屏障照常执行。
没有降低精确引用、声明覆盖或整体问题完成要求，也没有创建另一套 Agent 执行器。

## 迁移与验证

新增可选观察字段，无数据库列、事件版本、权限或提供商协议迁移。同步/API固定源码
按已有开发部署流程匹配，回退包即可；缺少新诊断的历史产物保持原义。
回归保留原拒绝与发布要求，并验证固定原因、双次费用记账、预算耗尽、取消/截止、
语义否定不重试、修正失败上限及无原文泄漏；正常任务入口核对验证步骤、持久验收、
最终引用和流式回答一致性。真实问题必须重新查询外部来源。
CI额外将有界的失败测试名称与异常类型投影到检查注释，保留原失败退出码与详细附件，
不公开断言正文；这是失败定位改进，不证明旧CI已经修复。
实际复测与剩余产品门禁见 [P1报告](../phases/PHASE-P1-REPORT.md)。
