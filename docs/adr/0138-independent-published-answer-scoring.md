# ADR0138：独立评价实际发布答案

状态：Accepted
日期：2026-09-15

## 背景

P1 验收驱动已固定资料、任务和配置并执行正常 Run，但默认 PendingScorer 从未给出独立
业务质量分数。候选自己的 grounding/VERIFIED 不能替代原文与金标评分。ADR0137 的真实
开发复测已能发布有引用的答案，但139.02秒仍超过120秒任务门槛，单次成功也不证明质量达标。

## 决策

在唯一 Python 控制面增加管理员评测接口 `POST /admin/evaluations/answer-score`。
调用者须通过 Policy Engine 的 `evaluations.write`，评测不会自动取得其他空间或原文权限。
服务端重新读取当前主体可见的真实已完成 Run、原 Turn 和唯一未替换文本产物，并核对问题、
答案摘要、原文摘要和审核引文。只将问题、最终文本、完整原文和冻结规则送入 Model Gateway；
候选计划、Claims、VERIFIED、Critic、Memory及工具不会进入评分提示。

新增独立评分器显式使用冻结配置中已登记的模型。必须评价整体事实正确性、任务完成度与
每条规则；所有规则唯一覆盖且均通过才可给 PASS。引用须逐字位于相应答案/原文并满足
实质长度，保存偏移、长度和摘要。结构无效、截断、缺项、模型故障均不可算通过。该协议
检查不能证明模型判断正确，独立校准与真实保留集仍是必需门禁。

评分有独立的32000输入、4000输出、0.25费用上限和45秒模型调用时间预算。时间预算只作用
于供应商网络请求，不能取消数据库查询使失败审计失效；端点回退共享截止时间。不会为得到
通过反复询问模型。沿用模型白名单、密级与私有路由，内容需要脱敏时阻断评分，避免把脱敏
版本误记为原文质量。评分前后检查当前主体、Policy、来源、答案和空间/资料密级。

ModelCall 已允许空 Run 外键，复用该形式保存独立评分调用，不改变候选 Run 的状态、
token、cost或答案。Model Gateway 在结果/异常中返回本次全部实际调用标识，包括端点
回退失败与超时；独立审计关联这些标识、主体、Policy、案例与答案摘要。没有第二套 Harness。

验收命令新增可选 `--scorer-model-profile`，从冻结模型目录解析，并通过相同认证源站
访问评分接口。无法解析时仍先生成 BLOCKED 报告，不新建候选任务。默认 PendingScorer
行为保留。报告记录评分模型与政策摘要；恢复重新读取和评分，旧分数不继承。

## 迁移、兼容与边界

无数据库结构迁移：复用已有 nullable ModelCall.run_id、不可变 AuditRecord 和私有报告。
HTTP接口、CLI选项及 ModelResult 字段为兼容新增，OpenAPI同步。原模型调用默认不新增时间
上限；新增超时记录 TIMEOUT，外部取消记录 CANCELLED。原候选轨迹、契约和评分指标不改写。
回退应用版本即可停止新评分，历史审计保留，不删除数据。

完整阶段仍须冻结评测器配置并校准、完成必需任务集、持久 Worker 版本证明及正式硬门。
评分子集成功继续 `phase_status=BLOCKED`、`promotion_eligible=false`；不能以模型分数
替代生产批准、签名或真实租户验收。当前不推广未经校准的评分结果为自我进化依据。
