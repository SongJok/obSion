# ADR0137：复核修正选择服务器原文片段

状态：Accepted
日期：2026-09-15

## 背景

ADR0136 已部署且通过完整回归，但真实问题两次复核均出现 `quote_not_exact`，
234.81秒后仍未发布答案。只读比较确认该 Run 的7段正文经 Model Gateway 脱敏后
均未改变。当前证据能排除这个样例的脱敏差异，不能根据响应摘要推测模型究竟
改写了哪些字词，也不能据此放宽原文匹配或增加无限重试。

## 决策

保留第一次复核协议与唯一一次修正的触发条件。第二次使用同一问题、候选、声明和
本轮授权 Evidence，将正文改为服务器确定的连续原文片段，要求模型选择
`evidence_id` 与 `passage_id`。标识绑定 Evidence、正文序号、偏移及文本摘要，
本次内存映射是唯一解析依据；不会从模型生成的文本或历史映射补建片段。

每片最多1500字符，优先在后半段换行边界切分，保留原字符顺序和空白。
需要脱敏的完整正文在切分前排除，避免秘密横跨切分边界而逃过脱敏，也不允许把
模型看不到的原文恢复为支持证据。无可选正文时停止修正；增加的标识开销仍受
120000字符上限和原剩余令牌/费用约束。

返回的引用只有严格的标识字段才被解析为服务器原文，再交给原 `validate_review`
核查精确匹配、实质长度、每条声明引用覆盖、全部声明和整体答案/问题完成判断。
未知、过期或跨 Evidence 标识拒绝为 `quote_reference_invalid`；附带自定义文本
不能覆盖服务器原文。为兼容旧模型适配器，原精确文本引用仍接受原严格校验。
片段标识只定位原文，不代表事实成立；语义否定、资料不足和不完整回答仍不发布。

预算、取消/截止、调用审计、来源版本/权限复验、Critic和发布屏障不变，没有新增
执行器或外部能力。持久化仍使用原文偏移、长度和摘要，不保存模型原始响应。

## 迁移与验证

无数据库或公开API结构迁移，历史验收产物保持原义。修正模型输入的私有协议由
请求指纹和部署源码版本标识；旧精确引用输出保持兼容，回退固定运行包即可。
新增测试覆盖长中文正文的连续切分、跨片秘密处理、未知/跨来源/额外字段/短引文
拒绝、语义否定和双次预算；普通HTTP任务入口验证解析后的来源、持久化和流式输出。
129项相关验证通过，真实开发部署复验仍待执行，不能当作真实答案质量通过。
