# P1 任务上下文合同与当前覆盖

状态：IN_PROGRESS
日期：2026-09-13

同一个 Thread 内，当前 Turn 保存用户本轮原话；RunIntent 保存本轮实际用于理解、计划、
检索和回答的任务问题。继承只适用于明确指代型追问，且只能来自当前主体已经捕获、
再次通过来源检查的最近会话快照。恢复上下文不授予工具权限。

## 已接入的字段与行为

| 内容 | 来源与持久化 | 当前行为 |
| --- | --- | --- |
| 本轮问题 | Turn.sanitized_input | 保留本轮文字，用于判定当前明确选择，不把恢复的旧问题误当成新输入 |
| 原任务问题 | 最近同主体 Run 的 RunIntent.question | 追问恢复有界原问题；明确新话题不继承；进入搜索、调查、作者和复核 |
| 仓库选择 | 当前 context_refs 或原 RunIntent.resolved_slots | 当前明确选择优先；历史选择改记 CONVERSATION 来源并关联快照；按当前可见仓库重查 |
| 服务选择 | 当前输入/context_refs 或原 resolved_slots | 同样保留选择来源；实际外部读取仍逐次经过 Gateway/Policy |
| 选定知识资料 | task_context.document_ids → selected_documents 槽位 | 最多 4 份；逐轮 Policy/ACL 重查当前版本，Gateway 固定版本读取；后续调查不能全库搜索 |
| 输出形式 | task_context.output_format / 本轮自然语言 → output_format 槽位 | AUTO/TABLE/BULLETS/REPORT；结构化明确值优先，后续指代追问保留 |
| 结构化约束 | task_context.constraints → task_constraints 槽位 | 最多 8 条，每条 1000 字符；作为用户要求传入作者与复核，不能覆盖权限或事实标准 |
| 原问题中的约束 | 继承的任务问题 | 作为用户任务文本传递，不能覆盖 Policy；不继承审批或执行授权 |

例如首轮问题提到 `selected-api` 与 `other-api`，但用户已经通过结构化选择指定
`selected-api`。随后“请再详细解释一下”仍使用这个选择，而不是再次把原问题的两个名称
作为两个新候选。若 `selected-api` 被撤权，不能自动使用唯一剩余的 `other-api`；必须
重新确认可访问的目标。当前用户明确选择另一个授权仓库时，以新选择为准。

结构化仓库选择使用既有普通任务接口，无新增权限入口：

```json
{
  "input": "查询创建订单的代码调用链",
  "context_refs": [{"type": "repository", "value": "selected-api"}]
}
```

此字段是用户提供的候选信息，不能绕过仓库 ACL。客户端不能通过它传入凭据、提升
能力权限或复用上轮审批。多轮正常入口回归使用本地合成代码图，不运行云效代码。

Web 普通提问框提供“仓库”选择按钮，按需读取授权目录，通过上述 context_refs 与附件
分开提交；原有 createTurn 调用保持兼容。提交成功后清除本轮显式指定，后续追问由
后台任务上下文继承；提交失败保留草稿，切换任务/工作空间清除选择。目录刷新先清空
旧候选，拒绝结果可见，过期目录响应不能带入新任务。“清除本轮仓库指定”不意味着
删除服务器已经保存的历史任务上下文。

## 资料与表达要求

普通任务接口示例（资料 ID 必须来自当前用户的授权索引）：

```json
{
  "input": "所选采购制度要求什么？",
  "context_refs": [{
    "type": "task_context",
    "document_ids": ["018f52c0-3f21-7000-8000-000000000001"],
    "output_format": "TABLE",
    "constraints": ["只描述财务复核条件"]
  }]
}
```

输出形式自动识别仅接受完整明确的格式请求；“不要用表格”重置为自动，引文中的“用表格”不改变设置。

字段省略保留继承资格；`document_ids: []` 解除范围，`constraints: []` 清除补充要求，
`output_format: "AUTO"` 重置输出形式。非空资料范围不能与同轮仓库选择并用。明确指定仓库
会解除旧资料范围，后续指代追问才继续继承当前任务。资料 ID 不能自行提供版本或凭据。

选定资料会把任务设为资料问答，初始计划只读所选资料；资料不足时只允许在相同资料版本
中续页读取，不能自行扩展全库搜索。资料被撤权或删除时停止；最近任务不可用时不能回退
到更早的主题。版本变化会使原引用失效，需要以明确的新请求读取当前资料，不能默用旧答案。

Web “资料与输出”使用既有受权知识搜索选择资料；显示当前任务保留的要求，可明确解除范围
或修改格式。撤销本轮设置只清除草稿，不删除服务器任务上下文。清空已经编辑过的补充要求
会显式清除原约束；未编辑的空框保持继承。提交失败保留草稿，成功或切换任务/空间清除草稿。

原生索引来源现纳入发布/历史权限检查，受管来源保持额外检查。已创建 Evidence 不因资料变化
而被改写，历史答案通过当前授权门隐藏。数据库结构未变；旧任务没有新槽位时沿用旧合同。

## 尚未覆盖

- 真实模型对输出形式和约束的独立质量验收，以及独立文件产物的完整跨入口选择体验。
- Web 与钉钉全部入口的上述字段选择体验和真实租户一致性验收。
- 全部来源的并发撤权、缓存/记忆/历史/产物统一失效验收。

这些缺项继续阻止 P1 完成；当前开发组合用例和合成运行不替代独立中文保留集的
目标识别正确率验收。实现和验证记录见 [P1 报告](../phases/PHASE-P1-REPORT.md)。
