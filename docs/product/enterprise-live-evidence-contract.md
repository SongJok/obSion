## 项目定位与当前事实

依据蓝图第四部分和用户最新范围决策，Obsion 是统一企业能力、证据与权限的工作台。
单一 Python Harness 负责理解、计划、执行、验证、反思和回答。外部访问经过 Capability
Gateway，授权由 Policy Engine 决定，正文作为不可信资料，不成为执行指令。

ADR0133 已为 `knowledge.search`/受管 `document.read` 接入提问后的来源重新采集：
现有 Worker 完成开始于当前 Run 之后的扫描，才允许其新读取正文进入本轮检索；
等待中不重置扫描游标或占用有效租约。正文不变也重新读取，版本无需因此递增。
发布前的版本/租约/ACL 检查继续保留；原生上传资料、开发样例和模型记忆不能冒充实时
钉钉、云效或日志查询。当前只实现受管钉钉遍历接线，真实租户、其他来源和完整质量验收
仍未完成。迁移、运行顺序与边界见 [ADR0133](../adr/0133-demand-fresh-enterprise-knowledge.md)。

## 必需运行事实

每轮企业事实回答必须保存至少一组与当前 Run/Step 关联的受授权外部查询事实：

| 事实 | 验证依据 |
| --- | --- |
| 发起主体、组织与资源范围 | 当前身份、Workspace 权限与逐次 Policy 决策 |
| 查询发起和响应时间 | 可信执行器记录；不能使用索引读取时间或模型输出时间替代 |
| 实际外部来源 | 固定连接器版本、外部操作、供应商来源与证据关联 |
| 读取完整性 | 版本/commit、分页边界、截断和不支持项；不得静默省略 |
| 当前问题关联 | 本轮查询开始后发生的外部调用；历史 Run 的旧调用不能复用为本轮证明 |
| 最终引用 | 文档原文位置或 commit/path/line，及其当前可访问性 |
| 验证结果 | 作者之外的复核结果、证据缺项、冲突和剩余不确定性 |

固定版本代码可以在多轮中复用版本选择，但每轮仍须通过受授权云效连接重查并读取；
版本固定是可复现性约束，不是跳过本轮来源查询的许可。云效严格只读，不运行云效源码。

索引允许帮助选择查询目标；强制实时模式的回答正文必须来自本轮取得的外部资料。
查询失败、Worker 离线、部分读取、权限到期和连接未配置必须各自保留状态，不能回退
到本地索引答案并标记“已实时核验”。用户显式上传/选择的原生资料使用其独立阅读合同，
界面与证据必须标明原生来源，不能作为企业实时来源的替代。

## 自主补查与信息补齐

Harness 按问题选择知识、代码/注释、日志/指标和已登记 Skill，并在证据不足或冲突时
提议下一次有界查询。下一步资源必须来自当前授权目录或此前真实结果，再逐次通过
Gateway/Policy。Skill 提供方法与证据要求，不能仅凭 Skill 说明产生企业业务事实。

反思结果保存缺什么、已查什么、为何继续或停止和下一步补齐条件。没有必要连接、身份
授权、原文或日志范围时，向用户给出具体补齐项和受治理的操作入口。预算耗尽或无法
验证时保留未完成，不把“主动补查过”计为答案正确，也不无限重试。

自我改进产生可审查的版本候选；冻结任务集、独立评分和回滚约束继续有效。成功经验不能
直接提升权限、替换已发布 Skill 或修改验收断言。

## 必需反向验收

1. 本地索引存在正确答案但外部不可达：不得发布索引事实为实时答案。
2. 外部内容在两轮间更新、删除或撤权：新一轮重新查证，旧证据不获得当前授权。
3. 对象未变而缓存有内容：仍能证明本轮外部调用，不能伪造刷新时间。
4. 部分/空结果、日志窗口不完整、分页截断：明确保留缺口并触发适当补查。
5. 供应商结果携带提示注入或伪造来源字段：不能改变工具、权限或可信调用时间。
6. 多主体、多组织、群成员变化与并发撤权：复用现有来源发布屏障并验证最终受众。
7. 多轮查询超时、取消、重启：维持原预算和可审计记录，不出现重复外部副作用。
8. 真正未执行的外部查询返回 NOT_RUN/BLOCKED，显式开发适配器只能证明本地契约。

实施继续按 P1—P5 合同推进：P1 先保证路由、正文和验收真实性；P2 打通知识及云效
外部读取，P4 扩展到日志与多源事故调查。任何阶段都不得提前宣称本合同已全量满足。
